# Xali's Potions — Distinct Bottle Shapes for Every Brew

Xali's Potions 9minecraft Resource Pack replaces vanilla potion bottles with unique, custom-shaped containers for every magical brew. In default Minecraft, potions only differ by liquid color, which makes sorting chests and inventories tricky during intense combat. This pack assigns custom artwork to each effect, placing clear symbols and distinct bottle silhouettes on Healing, Strength, Swiftness, and Poison brews.

## What this build is

An unofficial rebuild of **xalixilax**'s original work, kept running on current Minecraft releases by 9Minecraft Studios. Not affiliated with the original author and not endorsed by them.

Keeping a pack alive across releases is not a copy-paste job: each Minecraft version bumps the pack format and shuffles texture and model paths, so the tree gets re-mapped and every asset re-checked against the version it is built for. Anything the new release dropped is rebuilt rather than left pointing at a path that no longer exists.
